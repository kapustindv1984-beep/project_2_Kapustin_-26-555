# primitive-db

Простая CLI‑база данных на Python с интерактивным меню.

## Возможности

- Команды: `add`, `list`, `delete <номер>`, `help`, `exit`.
- Данные сохраняются в `data.json` между перезапусками.
- Архитектура на `uv` и соответствие PEP8 (проверено `ruff`).
- Готовый пакет для публикации (`.whl` + `.tar.gz`).
