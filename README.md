# primitive-db

Учебный проект: примитивная база данных на JSON-файлах с CLI-интерфейсом. Реализована без классов - только функции. Поддерживает создание таблиц, CRUD-операции, фильтрацию, кэширование выборок и подтверждение опасных действий.

## Требования

- Python >= 3.12
- Зависимости: prettytable, prompt, ruff, pytest (dev)

## Установка

Для установки проекта используйте Poetry:

```powershell
poetry install
```

Это создаст виртуальное окружение, установит зависимости и зарегистрирует пакет primitive-db в режиме разработки.

## Запуск

Запуск CLI-интерфейса согласно ТЗ:

```powershell
poetry run database
```

После запуска появится приглашение к вводу (`>`). Введите `exit` для завершения работы.

## Тесты

Для запуска тестов:

```powershell
poetry run pytest Tests/ -v
```

Все тесты должны завершаться статусом PASSED.

## Линтер

Проверка кода на соответствие стандартам:

```powershell
poetry run ruff check .
```

Результат должен быть: All checks passed!.

## Структура проекта

- `src/primitive_db/main.py` — точка входа
- `src/primitive_db/engine.py` — основной цикл и обработка ввода
- `src/primitive_db/core.py` — бизнес-логика (CRUD, валидация)
- `src/primitive_db/utils.py` — работа с файловой системой
- `src/primitive_db/parser.py` — разбор команд
- `src/primitive_db/decorators.py` — декораторы
- `src/primitive_db/constants.py` — константы

## Особенности реализации

- Отсутствие классов: вся логика реализована через функции.
- Именованные константы вместо «магических строк» (например, `META_FILE`, `DATA_DIR`).
- Семантичные имена переменных и функций в стиле snake_case.
- Docstring для всех функций.
